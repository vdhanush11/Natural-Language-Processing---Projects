# Model artifacts

Copy these generated files from Google Colab:

- word2vec_embeddings.npy
- fasttext_word_embeddings.npy
- fasttext_ngram_embeddings.npy
- word_to_idx.pkl
- idx_to_word.pkl
- ngram_to_idx.pkl
- tfidf_vectorizer.pkl
- test_word2vec_documents.npy
- test_fasttext_documents.npy

Optional training files such as `word2vec_skipgram.pt` and
`fasttext_skipgram.pt` are not required for inference.
